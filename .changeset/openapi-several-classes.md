Accept an array of exception classes as an `errors.throwers` or `errors.middleware` value, and document one response per class. The `ally.user` preset now documents the `500` of `E_OAUTH_MISSING_CODE` next to the `400` of `E_OAUTH_STATE_MISMATCH`. An `OA-E001` for an array names the item.
